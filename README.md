# Ket | Tarotista de Desarrollo Personal

Sitio web personal de lecturas de tarot.

## Cómo actualizar el sitio

1. Edita el archivo `index.html` con los cambios que quieras.
2. Guarda el archivo.
3. Ve a tu repositorio en GitHub.
4. Abre `index.html`, haz clic en el ícono de lápiz (editar).
5. Pega el contenido actualizado y haz clic en **Commit changes**.
6. En menos de 2 minutos tu sitio publicado se actualiza solo.

## Archivos

- `index.html` → toda la web (HTML + CSS + JS en un solo archivo)
- `ket-photo.jpg` → tu foto de perfil
- `.nojekyll` → evita errores en GitHub Pages
